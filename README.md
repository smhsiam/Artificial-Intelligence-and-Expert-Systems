# Artificial Intelligence and Expert Systems

An introduction to artificial intelligence covering intelligent agents, problem formulation, state spaces, uninformed and informed search, local search and optimization, constraint satisfaction problems, propositional logic, and first-order logic. Course materials and lab work for the Artificial Intelligence and Expert Systems course.

## Contents

- Lecture notes and reference materials
- AI lab exercises and Jupyter notebooks
- Datasets used for coursework

## Getting Started

To use the lab notebooks, install Python and Jupyter Notebook. Open a terminal in the project folder and run:

```bash
pip install notebook
jupyter notebook
